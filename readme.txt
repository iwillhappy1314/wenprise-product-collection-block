Add a product collection taxonomy for WooCommerce and display products by collection.

== Description ==

Create product collections alongside WooCommerce categories and tags, then display matching products in grid, list, or carousel layouts.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/wenprise-product-collection-block` directory, or install the plugin through the WordPress plugins screen directly.
1. Activate the plugin through the WordPress Plugins screen.
